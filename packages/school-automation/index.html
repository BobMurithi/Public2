Frequently asked questions

Everything you need to know before getting started.

Will parents need a special app?

No - everything works on WhatsApp, which almost every parent already uses.

Does it handle different classes and fee amounts?

Yes - fee structures per class, term and category are all supported.

Can we still send personalised messages?

Absolutely - reminders are automatic, but can be customised with specific details.

Does it work with M-Pesa?

Yes - via the M-Pesa Daraja API. Payment confirmations are detected and logged automatically.
