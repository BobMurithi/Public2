## 🤖 n8n Automation Workflows Required

| Workflow | Trigger | What it does |
|---|---|---|
| **Blog Auto-Update** | Schedule (every 6hrs) | Pulls RSS feeds → GPT rewrites → updates `blog-feed.json` → pushes to GitHub |
| **Lead Capture** | Webhook `/webhook/new-lead` | Receives form/WhatsApp lead → logs to Google Sheets → sends WhatsApp alert to admin |
| **Client Auth** | Webhook `/webhook/auth` | Validates client email+ID → returns client data for dashboard |
| **Payment Confirmation** | M-Pesa Daraja webhook | Confirms payment → updates client record → sends receipt via WhatsApp |
| **Newsletter Subscribe** | Webhook `/webhook/newsletter` | Saves subscriber → sends welcome email/WhatsApp |
| **Support Ticket** | Webhook `/webhook/support` | Receives ticket → notifies admin on WhatsApp → logs to sheet |
| **Blog Refresh (Manual)** | Webhook `/webhook/refresh-blog` | Manually trigger blog refresh from admin panel |
| **Payment Reminder** | Schedule (monthly -3 days) | Checks upcoming renewals → sends WhatsApp reminders to clients |

## 🚀 Deployment

This site is deployed automatically via **Cloudflare Pages**.

Every `git push` to `main` triggers a new deploy (~30 seconds).

```bash
# Make changes, then:
git add .
git commit -m "Your change description"
git push
# → Cloudflare Pages auto-deploys
```

### Branch Strategy
| Branch | Purpose |
|---|---|
| `main` | Production — live site |
| `dev` | Development / staging |

## 📊 Phases Completed

### Phase 1-3: Core Site + Content
- Homepage, 8 service pages, blog, dashboard, admin
- Responsive design system (CSS variables, mobile-first)
- Dark mode toggle (localStorage: `bobsave_dark_mode`)
- Bootstrap 5 integration + custom theme

### Phase 4: Directory-Style SEO Routes
- 20 industries + 37 niches + 4 packages + 9 automations = 70 data-driven pages
- Directory routes: `/industries/{slug}/`, `/industries/{parent}/{slug}/`, `/packages/{slug}/`, `/automations/{slug}/`
- 301 redirects from legacy flat URLs via `_redirects` (70 rules)
- Generator scripts: `gen-phase4.ps1`, `gen-service-pages.ps1`

### Phase 5: SEO + Structured Data
- `robots.txt` -- Allow all, Sitemap reference
- `sitemap.xml` -- 88 URLs (generated by `gen-seo.ps1`)
- `404.html` -- Custom error page with dark mode, AdSense, nav
- JSON-LD structured data on all generated pages:
  - Organization schema (homepage)
  - BreadcrumbList (all pages)
  - FAQPage (industries, niches, packages, automations)
  - Service schema (automations)
- Canonical tags on all HTML pages

### Phase 6: Lead Funnel + Client Delivery
- `get-started.html` -- Lead capture form (name, WhatsApp, email, business, industry, interest, tools, goal, message)
  - Stores leads in localStorage `bs_leads`
  - POSTs to n8n webhook (`BS_WEBHOOK_URL` constant -- set in production)
  - Opens WhatsApp with prefilled summary
  - Static industry dropdown (20 industries) + fetch refresh
- `admin.html` -- Lead pipeline with status workflow:
  - Statuses: new, contacted, paid, configuring, testing, delivered, lost
  - Merges localStorage leads into admin data
  - Status persistence via `updateStoredStatus()`
  - 4-card stats: New / Contacted / Paid+Converted / Delivered
- `dashboard.html` -- Client delivery timeline:
  - 6-stage pipeline visualization (New, Contacted, Paid, Configuring, Testing, Delivered)
  - Matches session user (`bs_user`) against stored leads
- CTA routing: all phase pages, service pages, index to `get-started.html` with query params

### Phase 7: Quality Assurance
- **Static audit** (`qa-static.js`): 89 HTML files, 4058 links checked, 0 real issues
- **Browser QA** (`qa-node.js`): 34 viewport checks across 14 pages -- 0 overflow, 0 broken images, 0 real console errors
- **Overflow fixes**: index int-chip grid, 404 nav wrap, service-pages nav collapse at 1120px
- **Dark mode CSS** (`bobsave-dark.css`): updated nav media query to 1120px
